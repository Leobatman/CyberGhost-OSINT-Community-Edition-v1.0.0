# Responsible Use Policy

**CyberGhost OSINT** is an Open Source intelligence gathering framework designed strictly for defensive purposes, security research, and authorized penetration testing.

By using this software, you agree to adhere to the following principles:

## 1. Authorized Use Only
You must only use CyberGhost OSINT against targets that you own, operate, or have explicit, documented authorization to investigate. Using this tool against third-party infrastructure without consent is strictly prohibited.

## 2. No Malicious Activity
This tool is for passive intelligence gathering and analysis. It must not be used to facilitate cyberattacks, unauthorized exploitation, harassment, stalking, doxxing, or any activity that violates the law.

## 3. Rate Limiting and Respect
The tool queries public resources (e.g., DNS, RDAP, crt.sh). Do not modify the tool to aggressively spam or overload these public services. Respect the rate limits of Open Source Intelligence providers.

## 4. Privacy
Do not use this tool to collect personally identifiable information (PII) for malicious purposes. The OSINT data gathered should be treated responsibly and in accordance with local privacy laws (such as GDPR or LGPD).

## 5. Liability
The authors and maintainers of CyberGhost OSINT assume **no liability** for how this software is used. The user is entirely responsible for their actions and for ensuring they comply with all applicable local, national, and international laws.
